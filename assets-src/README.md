# Source images (not served)

Originals and working sources live here, outside `public/`, so Next.js does not serve them. Sites use the optimised copies under `public/images/`.

`2026-10-17/`: screenshots supplied on 2026-10-17 (colour reference and the MAGDELENA photo sources). They were recompressed losslessly: the unused alpha channel was dropped and the PNG re-encoded at maximum compression. Every file was checked to be pixel-identical to the original (43.0 MB to 25.6 MB). Git history still holds the first, larger versions.
